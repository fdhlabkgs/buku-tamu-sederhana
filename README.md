# Buku Tamu Kondangan

Sistem Pencatatan Tamu Kondangan Digital Sederhana untuk Uji Kompetensi Junior Web Developer

## Struktur Folder

- `assets/css/style.css` : Desain Tampilan antarmuka web tamu kondangan
- `assets/img/` : Direktori asset gambar
- `assets/js/app.js` : Logika pembacaan JSON
- `bagan-alir.dio` : Dokumentasi Algoritma dan flowchart
- `data/tamu.json` : Sumber data tamu kondangan
- `index.html` : Halaman Utama Aplikasi / Kerangka Aplikasi web
